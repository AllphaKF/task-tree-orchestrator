# Branch 文件模板（task-tree/branches/<枝名>.md）

> 管理者草创时复制本模板创建每个枝的文件（包括预埋占位枝）。
> **Limitations 必须在草创阶段写满写细，即使该枝尚未激活。** 执行者只被允许追加 Results / BlockedBy / NeedsAuthorization 三区，其余区段只有管理者可改。

# <枝名>（<枝号>）

## Status

`INACTIVE | READY | RUNNING | BLOCKED | DONE | DEPRECATED`（管理者维护；可在状态词后加一句注记说明现状，如：`BLOCKED`（等 Gate1 裁定））

- 当前轮次：R<序号>（RUNNING 时填写；由管理者在投递时更新）
- 执行者：<谁>（RUNNING 时填写）

## Goal（目标）

<本枝要达成的可验收目标，1–3 句话 + 验收标准。>

## Tasks（任务分解）

<按「单轮 ≤ 20 分钟」拆分的原子任务列表，管理者随进度勾选/追加：
- [ ] T1：<任务描述>（轮次 R<序号>，状态：进行中/已完成/已撤销）
- [ ] T2：<…>
>

## Limitations（边界——预埋结构的关键，宁细勿粗）

### 1. 允许做什么

- <本枝职责范围内可执行的动作，逐条列出>

### 2. 禁止做什么（不越权清单）

- <明确禁止，逐条列出。示例：不得修改 <其他枝> 的任何文件；不得代填需人类授权的字段；不得执行 <列举具体命令/动作>；不得扩大样本/范围；不得外发数据；不得修改其他 branch 的产出文件>

### 3. 依赖的上游枝

- <本枝开工前必须等待/读取的枝及其产出，写明格式与位置>

### 4. 产出供哪些下游枝

- <本枝结果的消费者、交付格式、落盘位置>

## Results（结果区——执行者每轮追加，管理者巡检后确认）

```
### R<序号>（<执行者>，<日期>）
- 做了什么：<一句话>
- 产出文件：<路径清单>
- 核验结果：<执行者自报的核验；管理者独立核验结论另注>
- 结论：<完成/部分完成/受阻>
```

## BlockedBy（等待项——执行者更新）

- <「等待 <枝名> 完成后才能继续 <任务>」逐条列出；依赖解除后由管理者移除并解锁本枝>

## NeedsAuthorization（待授权项——执行者更新，管理者汇总呈递人类）

- <需要人类授权才能做的事 + 理由 + 建议选项；人类批复后由管理者移入 B0-governance.md 授权台账>

## 授权台账（B0-governance 专用，只追加，管理者维护）

> 人类的 Gate 决定在此落账，格式：

| 日期 | 决定 | 依据 | 连锁动作 |
|---|---|---|---|
| YYYY-MM-DD | GateN：裁定内容 | 裁定依据/事实 | 裁定后须执行的连锁任务 |
